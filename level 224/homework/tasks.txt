2) შექმენით პატარა React Native პროექტი თავისუფალ თემაზე. პროექტში აუცილებლად 
გამოიყენეთ შემდეგი თემები:

- Pressable Components — Pressable-ის გამოყენება ინტერაქტიული ღილაკებისა და ელემენტებისთვის.
- User Inputs — მომხმარებლისგან ინფორმაციის მიღება TextInput-ის საშუალებით.
- Keyboard Management — კლავიატურის სწორად მართვა input-ებთან მუშაობისას.
- Scrolling — დიდი რაოდენობის ინფორმაციის სქროლვის შესაძლებლობა, მაგალითად FlatList.
- Modals — დამატებითი ინფორმაციის ან ფორმის ჩვენება Modal-ის საშუალებით.
- Alerts — მომხმარებლისთვის შეტყობინებებისა და დადასტურების ფანჯრების ჩვენება Alert-ის გამოყენებით.
- Loading Indicators — მონაცემების ჩატვირთვისას loading-ის ჩვენება ActivityIndicator-ის გამოყენებით.
