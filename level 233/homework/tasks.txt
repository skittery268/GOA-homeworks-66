2) შექმენით Online Shop-ის მობილური აპლიკაცია შემდეგი ტექნოლოგიების გამოყენებით: React Native, Express.js და MongoDB.

Online Shop-ში პროდუქტებზე უნდა გქონდეთ სრული CRUD ფუნქციონალი - პროდუქტის დამატება, ყველა/კონკრეტული პროდუქტის წამოღება, რედაქტირება და წაშლა.

მობილური აპლიკაციის შექმნისას აუცილებლად გაითვალისწინეთ Offline რეჟიმი და ინტერნეტის პრობლემები. მოახდინეთ მიღებული მონაცემების Cache-ში შენახვა, რათა ინტერნეტის გათიშვის შემთხვევაში მომხმარებელს ბოლოს მიღებული მონაცემები მაინც გამოუჩნდეს. გამოიყენეთ AsyncStorage ან მსგავსი საშუალება.

API მოთხოვნებისთვის გამოიყენეთ Axios/Fetch Retry მექანიზმი, რათა დროებითი Network Error-ის შემთხვევაში მოთხოვნა რამდენჯერმე განმეორდეს. Retry არ უნდა იყოს უსასრულო.

ასევე დაამუშავეთ Loading, Error და Offline მდგომარეობები და მომხმარებელს შესაბამისი ინფორმაცია აჩვენეთ.
