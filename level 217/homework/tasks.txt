2) შექმენით პატარა Game Hub Next.js-ში, სადაც მომხმარებელს შეეძლება თამაშების, ჟანრებისა და თამაშების გზამკვლევების ნახვა.

ძირითადი მოთხოვნები
1. მთავარი გვერდი (/)

აჩვენეთ თამაშების სია. თითოეულ თამაშს ჰქონდეს:

- სახელი
- ჟანრი
- მოკლე აღწერა
- დეტალების გვერდზე გადასასვლელი ღილაკი

2. Dynamic Route — თამაშის გვერდი

შექმენით:

/games/[id]

მაგალითად:

/games/1
/games/2
/games/3

id-ის მიხედვით უნდა გამოჩნდეს კონკრეტული თამაშის ინფორმაცია.

თუ მომხმარებელი არარსებულ id-ზე გადავიდა, გამოიყენეთ not-found.tsx და აჩვენეთ შესაბამისი შეტყობინება.

3. Dynamic Route — ჟანრები

შექმენით:

/genres/[genre]

მაგალითად:

/genres/action
/genres/rpg
/genres/racing

გვერდზე აჩვენეთ კონკრეტულ ჟანრში არსებული თამაშები.

თუ ასეთი ჟანრი არ არსებობს, უნდა გამოჩნდეს not-found.tsx.

4. Catch-All Route — Game Guides

შექმენით:

/guides/[...slug]

მაგალითად:

/guides
/guides/minecraft
/guides/minecraft/building
/guides/minecraft/building/house

Catch-All Route-მა უნდა მიიღოს slug და ეკრანზე აჩვენოს მიღებული route-ის თითოეული ნაწილი.

მაგალითად:

Game: Minecraft

Path:
Minecraft → Building → House

5. Layout

შექმენით შესაბამისი layout.tsx, რომელიც გამოყენებული იქნება საერთო UI-სთვის.

Layout-ში დაამატეთ:

Header
Navigation
მთავარი გვერდების Link-ები
Footer

Navigation-იდან შესაძლებელი უნდა იყოს Home, Games, Genres და Guides სექციებზე გადასვლა.

6. Error Handling

შექმენით error.tsx.

მოიფიქრეთ ისეთი სიტუაცია, როდესაც კონკრეტული გვერდის ჩატვირთვისას შეიძლება მოხდეს შეცდომა და აჩვენეთ მომხმარებელს:

შეცდომის შეტყობინება
„Try again“ ღილაკი

Try again ღილაკმა უნდა გამოიყენოს შესაბამისი ფუნქცია გვერდის ხელახლა ჩასატვირთად.
